The ranking therefore uses **GitHub stars as the primary adoption proxy**, checked alongside forks, recency, scope, and whether the repository is actually a reusable skills corpus/standard rather than a coincidental search match.

## Inclusion rule

A repository is included when it has strong current adoption signals **or** is a canonical official/standards source that materially shapes how Agent Skills are authored or distributed. Aggregators are clearly labelled so readers do not mistake mirrored/indexed skills for original upstream ownership.

## Maintenance

When refreshing this list, check the live repository, update the snapshot date, remove archived/dead sources, and resist ranking by stars alone: active specialist libraries can be more useful than a larger generic repository for a specific task.
