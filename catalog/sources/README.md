# Prominent Agent Skills repositories — research snapshot

**Snapshot date:** 2026-08-30

This page answers a practical question: **which public repositories are currently useful enough to bookmark when looking for Agent Skills, rules, helpers, standards, or reusable agent workflows?**

It is not a definitive “most used” leaderboard. There is no universal public installation counter shared across Claude Code, Codex, Cursor, Copilot, Gemini CLI and other consumers. GitHub stars, forks, recency and community activity are useful adoption signals, but they are not usage telemetry.

The list is therefore grouped by **why the source matters**, not by a fragile numeric ranking.

## Selection method

Sources were discovered through live GitHub searches around Agent Skills / Claude skills / Codex skills, then checked for actual reusable content and upstream identity. A source is retained when it has one or more of these signals:

- strong current community adoption;
- official/canonical ownership;
- material influence on the Agent Skills ecosystem;
- specialist depth that is useful despite a smaller audience;
- discovery/tooling value that helps locate or manage real skills.

Forks, mirrors, thin reposts and unrelated repositories are excluded where identifiable. Discovery indexes are labelled as such so they are never mistaken for original upstream ownership.

## Maintenance

On refresh, re-check every source live, update this date, fix renames, remove dead/archived entries, and reconsider the grouping. Do not copy mutable star/fork counts into the individual cards: the catalogue should remain useful after the snapshot ages.
