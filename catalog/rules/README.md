# Rule systems

Project path-scoped rules are deliberately **not copied** into this catalogue. They encode local architecture and age quickly, so the source repo is the only trustworthy copy.

## Current rule sources

- **PocketRPG:** https://github.com/howellsryan/pocketRPG/tree/main/.claude/rules — gameplay engine, co-op/raids, server authority, UI styling, single-file build, PvP, MCP, chat, testing and other path-scoped knowledge.
- **Pitch:** https://github.com/howellsryan/pitch/tree/main/.claude/rules — currently includes the Svelte 5 project rule alongside its skill set.
- **Agent-Template:** https://github.com/howellsryan/Agent-Template/tree/main/.claude/rules — format/example material only.

## Rule of thumb

If guidance depends on a particular path, subsystem, data format, or product invariant, keep it in the owning repo and link it here. Only portable workflows deserve reusable skill cards.
