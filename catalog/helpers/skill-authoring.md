# Skill authoring & progressive disclosure

**Type:** External reference helper

**What it does:** Provides the standards and design philosophy behind small composable agent skills, trigger-focused descriptions, and progressive disclosure.

**References:**

- Anthropic Agent Skills engineering article: https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills
- Agent Skills open standard: https://agentskills.io
- Anthropic skills repository: https://github.com/anthropics/skills
- Matt Pocock skills repository: https://github.com/mattpocock/skills

**Use:** When adding a new card/skill, keep the trigger description precise, avoid restating model defaults, and prefer small composable workflows over a monolith.
