# pr-changelog

**Type:** First-party project-pattern

**What it does:** Treats the PR title/body as player- or user-facing release copy when merges automatically publish to a changelog channel.

**Canonical source:** https://github.com/howellsryan/pocketRPG/tree/main/.claude/skills/pr-changelog

**Used in:** `pocketRPG`, `chat`

**Get the latest:** Copy from the product whose publishing pipeline most closely matches the destination, then change audience/channel assumptions.
