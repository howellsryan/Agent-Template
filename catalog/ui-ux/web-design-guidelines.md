# web-design-guidelines

**What it does:** Audits UI code against Vercel’s living Web Interface Guidelines, including accessibility, keyboard/focus behavior, forms, layout, animation, responsive behavior, copy, and interaction quality.

**Skill source:** https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines

**Guideline source:** https://github.com/vercel-labs/web-interface-guidelines

**Get the latest:** `npx skills add https://github.com/vercel-labs/agent-skills --skill web-design-guidelines`. The skill should use the current guideline source when reviewing UI.
